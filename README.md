# CMCL — C Minerva Launcher

Настольный лаунчер Minecraft на **Electron**: установка сборок с разными загрузчиками, менеджер модов, серверы, аккаунты ELY.by, 3D-скины и умное распределение ОЗУ.

## Возможности

### Сборки
- **Все основные загрузчики**: Vanilla, Fabric, Quilt, Forge, NeoForge — с реальной установкой (версии, библиотеки, лоадеры скачиваются и раскладываются автоматически).
- Скачивание версий игры, ассетов, библиотек и нативных библиотек с зеркалами Mojang (настраиваются).
- **Умное распределение ОЗУ**: лаунчер сам подбирает память по версии игры и количеству модов. Ручные `Xms`/`Xmx` и переопределение для конкретной сборки всегда главнее.
- Импорт/экспорт сборок в формате **`.ccli`** — конфиги прямо внутри (есть режим gzip+base64), моды и паки описываются именем/версией/источником.
- **Группировка сборок** в списке: по версии игры, загрузчику или статусу.
- Свойства каждой сборки: версия, загрузчик, статус, папка, Java-версия.

### Моды
- Встроенный браузер контента с поиском по **Modrinth** и **CurseForge** (для CurseForge нужен бесплатный API-ключ).
- Категории: моды, модпаки, ресурс-паки, текстур-паки, миры, шейдер-паки. Для Vanilla-сборок кнопка «Моды» скрыта.
- Установленные моды: **смена версии** в один клик (с проверкой совместимости с версией игры и загрузчиком) и удаление.
- **Дерево зависимостей** мода: обязательные/опциональные/встроенные связи, видно что установлено, недостающие зависимости ставятся прямо из дерева.
- Установка целых модпаков одной кнопкой.

### Серверы
- Локальные серверы в папке `serv/` прямо из лаунчера: **Vanilla, Paper, Purpur, Forge, Fabric**.
- Установка ядра, `eula.txt`, `server.properties`, скрипты запуска `start.sh` / `start.bat`.
- Запуск/остановка, консоль с командами, редактирование properties, готовые папки.

### Аккаунты и скины
- **Оффлайн-аккаунты** и **реальный вход через ELY.by** (`authserver.ely.by`, Yggdrasil): пароль, 2FA (`пароль:код`), validate → refresh сессии перед запуском.
- **3D-превью скинов** (skinview3d), выбор одной кнопкой: скины с ELY.by + свои PNG-файлы из папок `ver/skins` и `<папка лаунчера>/skins`.
- **Скины видны в игре**: подключается `authlib-injector`, сессия и текстуры идут через ELY.by, берётся реальный UUID профиля.
- Добавление скинов файлами или папкой прямо из интерфейса.

### Запуск
- Автоподбор Java под версию игры (встроенные Temurin + системная Java), принудительный выбор версии или свой путь к `java`/`javaw.exe`.
- Обход проблемы **LWJGL 2** (Minecraft ≤ 1.12.2 без `xrandr`) — авто/всегда/выключено.
- Глобальные и по-сборочные JVM-флаги, доп. аргументы игры, размер окна и полный экран.
- Консоль с выводом лога игры в реальном времени, опционально — запись лога в файл `ver/logs/`.
- Сворачивание или закрытие лаунчера при запуске игры.

### Интерфейс
- Тёмная тема в стиле Minecraft, фон-сцена с дождём и светлячками, анимации (можно отключить).
- Кастомная рамка окна (frameless) с кнопками свернуть/закрыть, фиксированный размер, запоминание позиции.
- Масштаб интерфейса 60–200 % (применяется сразу).
- Модальные окна, подтверждения удаления (отключаемы), быстрый доступ к папкам лаунчера.

## Настройки

9 вкладок: **Java**, **Сборки** (переопределения по каждой сборке), **Запуск**, **Аккаунты**, **Серверы**, **Загрузки** (потоки, попытки, зеркала, таймаут), **Контент** (источник по умолчанию, ключ CurseForge, скины ely.by), **Интерфейс**, **Папки**.

Всё валидируется и сохраняется в `ver/settings.json`; есть сброс к умолчаниям.

## Установка

### Готовый exe (Windows)
Скачай `CMCL Setup 1.0.0.exe` (установщик NSIS) или `CMCL 1.0.0.exe` (переносная версия) из [Releases](https://github.com/imvaner/C-MineCraft-Launcher/releases) репозитория.

> Exe не подписан сертификатом — Windows покажет предупреждение SmartScreen. Нажми «Подробнее» → «Всё равно запустить».

### Из исходников
```bash
git clone https://github.com/imvaner/C-MineCraft-Launcher.git
cd C-MineCraft-Launcher
npm install

npm start          # запуск в разработке
npm run build:win  # сборка exe (Windows x64, NSIS + portable)
```

Сборка exe работает и на Linux — для NSIS используется Wine.

**Требования**: Node.js 18+ (для разработки). Для игры Java скачивается автоматически.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.js` | Главный процесс Electron: установка версий, запуск игры, API Modrinth/CurseForge, серверы, аккаунты, настройки |
| `preload.js` | Мост IPC между главным процессом и рендерером (`contextIsolation`) |
| `index.html` | Разметка интерфейса и рендерер-логика |
| `style.css` | Стили (тёмная тема, анимации, модалки) |
| `skinview3d.bundle.js` | 3D-превью скинов (skinview3d 3.4.2) |
| `package.json` | Зависимости и конфиг electron-builder |

**Данные лаунчера** (создаются рядом с exe, в git не входят):

```
ver/            сборки, аккаунты, настройки, Java, кеш скинов, логи
serv/           локальные серверы
skins/          свои скины (PNG)
dist/           собранные exe
```

## Формат `.ccli`

Текстовый файл экспорта сборки:

```
# CCLI/1
```

Содержит только **названия, версии и источник** модов/паков (без бинарников), конфиги — инлайн (plain text или gzip+base64, выбор при экспорте). Импорт ищет файлы по порядку: `versionId` → `sha1` → `projectId`.

## Используемые API

- **Modrinth** — `api.modrinth.com/v2`
- **CurseForge** — `api.curseforge.com/v1` (нужен API-ключ)
- **ELY.by** — `authserver.ely.by` (вход/сессия), `skinsystem.ely.by` (скины)
- **Mojang** — версии, ассеты, библиотеки (+ зеркала)
- **Adoptium** — скачивание Java (Temurin)
- **Paper / Purpur / Fabric / Forge** — ядра серверов и лоадеры
- **authlib-injector** — скины ELY.by внутри игры
